# Prompty do zdjęć (ChatGPT) – Liyas Lounge

**Jak używać:** skopiuj prompt → wklej do ChatGPT → pobierz obraz → wyślij mi (albo sam:
`python3 scripts/add-image.py plik.png <nazwa>` i `node scripts/build.mjs`).

Wspólny styl jest już w każdym prompcie (czarno-złoty, białe kalie/orchidee, ciepłe światło), więc pasują do obecnych zdjęć.

**Nie generuj AI:** portretu właścicielki (prawdziwe zdjęcie → `team-inhaberin`), zdjęć klientek do opinii
ani „przed/po”.
